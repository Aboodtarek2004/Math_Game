# 🧮 Math Quiz Game

A fun and interactive **C++ console application** that challenges players with randomly generated math questions. 🎯 Improve your arithmetic skills by solving addition, subtraction, multiplication, and division problems across different difficulty levels.

---

## ✨ Features

* 🎲 Randomly generated math questions
* 🔢 Choose **1–10** questions per quiz
* 📈 Multiple difficulty levels:

  * 🟢 Easy
  * 🟡 Medium
  * 🔴 Hard
  * 🎲 Mixed
* ➕➖✖️➗ Select operation type:

  * Addition
  * Subtraction
  * Multiplication
  * Division
  * Mixed Operations
* ✅ Instant feedback after every answer
* 🎨 Console color changes:

  * 🟢 Green for correct answers
  * 🔴 Red for incorrect answers
* 📊 Final quiz report with detailed statistics
* 🔄 Play unlimited rounds

---

## 🚀 How It Works

1. 📝 Choose the number of questions.
2. 🎯 Select the difficulty level.
3. ➕ Choose the math operation.
4. 🤔 Answer each randomly generated question.
5. ✅ Receive immediate feedback after every answer.
6. 🏆 View your final score and quiz summary.
7. 🔁 Play again if you want another challenge!

## ▶️ How to Run

Compile the project:

```bash
g++ MathQuizGame.cpp -o MathQuizGame
```

Run the executable:

**Linux / macOS**

```bash
./MathQuizGame
```

**Windows**

```bash
MathQuizGame.exe
```
